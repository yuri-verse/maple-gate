전투력 계산식 — 검증

공식 25개 항으로 실계정 2경 4021조를 재현했습니다. 차이 0.02% 이내.

1타 피해식 — 검증

실제 화면 피해 200조~900조, 모델 예측 190조~985조로 범위가 겹칩니다.

스테이지 데이터 — 검증

CreatureStatTable × MonsterTierTable ÷ 1000으로 조립. 방어력·회피 포함.

스폰 타이밍 — 확정

맵 정의 Camps[].InitTimeMs 그대로. 캠프 20개가 1초 간격으로 나옵니다.

돌파의 구조 — 확정

화면 타이머 없음. 몬스터가 출구에 닿으면 즉시 실패하는 방어전입니다.
